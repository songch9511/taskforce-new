# 처리방침 · 약관 자체 검토 (L9 대신, 베타)

작성: 2026-09-29. 관련: [README.md](README.md) "법률 검토 항목" 1~9 · 게시 규칙 1 · [privacy.ko.md](privacy.ko.md) · [terms.ko.md](terms.ko.md)

D1 · D2는 2026-10-04에 더했다: 이용자가 시작한 초안(D9a-1, 베타 1.4)에서 새로 생긴 쟁점이라 README "법률 검토 항목" 번호와 따로 둔다.

**결정 (2026-09-29, 사용자):** 베타는 변호사 검토 없이 회사가 직접 검토해 게시한다. 법은 처리방침 게시에 변호사 검토를 요구하지 않고, 문안의 책임은 어느 쪽이든 회사에 있다. 이 문서는 README "법률 검토 항목" 9개를 하나씩 정리한 결정표다. **유료화 · Marketplace · Google 민감 범위 심사 전에는 변호사에게 한 번 검토받는다**(아래 "다시 볼 때").

작성자는 변호사가 아니다. 아래 "권장"은 공개된 법령 · 개인정보보호위원회 「개인정보 처리방침 작성지침」 · 각 서비스 약관을 읽고 보수적으로 고른 것이고, 법률 자문이 아니다.
