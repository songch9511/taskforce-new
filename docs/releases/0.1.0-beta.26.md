# Taskforce for Mac — 0.1.0 (26) beta

- Task List settings now use the same centered layout and grouped rows as the other settings pages. Section names align on the left and row-count controls on the right.
- Existing section limits, the All default and Show More behavior are preserved.

## Install

Requires macOS 15 or later. Open the DMG, move Taskforce to Applications, and replace the previous app. Your account and task data are retained. Settings → About shows version 0.1.0 and Build 26.

Google sign-in and service connections are separate. Available connections depend on beta availability and provider approval.
