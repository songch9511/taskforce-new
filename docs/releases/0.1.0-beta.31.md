# Taskforce for Mac 0.1.0 (31)

- Set a global Open Settings shortcut in Keyboard Shortcuts. Record, change, or remove it alongside the launcher shortcut; conflicting shortcuts keep the previous setting and show a retry option.
- Keep the Settings sidebar and outer margins aligned when switching to About.
- Open Account directly inside Settings.
- See your plan, AI allowance progress, reset date, and execution credits in a clearer Usage & Credits layout.
- Use a larger Taskforce mark on a native-style macOS app icon.

Requires macOS 15 or later. Existing account data and connections are preserved.
