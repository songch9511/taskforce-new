# Taskforce for Mac — 0.1.0 (25) beta

Taskforce keeps the work you committed to close to its source, in a native Mac launcher.

- Open your tasks with Option–Space and inspect the source quote behind an AI-created task.
- Review uncertain tasks, track progress and add tasks directly.
- Open Settings → About to check the installed version, build number and build context, or copy them for a bug report.
- Read the refreshed GitHub guide with native demo screenshots and installation instructions.

## Install

Requires macOS 15 or later and Google sign-in. Open the DMG, drag Taskforce to Applications, then launch Taskforce from Applications. Service connections are separate from sign-in and depend on beta availability and provider approval. iPhone is not included in this beta.

Use the DMG attached to this release. The source-code archives are for developers. Compare the downloaded file with the attached SHA-256 checksum when needed.
